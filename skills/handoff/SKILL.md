description: Writes end of session handover;handoff note to capture details of what was achieved in this session.
model: haiku

When writing handoff:
- Create a handoff directory in the root directory of the project if one doesnt exist
- The handoff file should be named as DDMMYY_#{handover_number_for_the_day}_major_act_of_session.md
- Add detail about initial intent of the session
  - What
  - Why
- Add detail about the bead/issue/task that was worked on
- Add the flow of the session, what was done, and in which order. The motivation for the changes, and discovery made, be as detailed as possible
- List all the files that were touched as part of the session
- List all user explicit asks/steers. What did they care about the most. If there were multiple things, list them in order of process.
- List what to do in the next session
  - Where to start
  - What to parallelize?
  - Is there a dependency chain to honor?
  - Did we figure out models to use for each of these changes?
- Add model :bot:
  - list models used in the session
    - driver model: 
    - explorer model:
    - implementer model:
